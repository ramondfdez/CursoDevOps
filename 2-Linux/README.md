# 2 - Linux y Shell Scripting

## Objetivo

Practicar comandos basicos de Linux, automatizacion con Bash y gestion de permisos.

## Ejercicios incluidos

- `script.sh`: crea estructura de carpetas y un archivo de notas.
- `script2.sh`: copia credenciales y aplica permisos restrictivos.

## Ejecucion

```bash
cd 2-Linux
bash script.sh
bash script2.sh
```

## Resultado esperado

- Se crean carpetas y archivos segun los scripts.
- Se aplican permisos definidos en el ejercicio.

## Nota didactica

El objetivo es comprender la diferencia entre funcionalidad y seguridad: un script puede funcionar, pero no siempre es la mejor practica para entornos productivos.
