# Docker Compose - Demo 1

## Objetivo

Levantar dos servicios (web + base de datos) con un solo comando.

## Archivo clave

- `docker-compose.yml`

## Comandos

```bash
cd 4-DockerCompose/demo1
docker compose up -d
```

Para apagar:

```bash
docker compose down
```

## Verificacion

Abrir `http://localhost:8080`.
