# Docker Compose - Ejercicio Web

## Objetivo

Desplegar una web Nginx usando imagen custom y compose.

## Archivos clave

- `docker-compose.yml`
- `Dockerfile`
- `default.conf`
- `index.html`

## Comandos

```bash
cd 4-DockerCompose/ejercicioweb
docker compose build
docker compose up -d
```

## Verificacion

Abrir `http://localhost:8080`.
