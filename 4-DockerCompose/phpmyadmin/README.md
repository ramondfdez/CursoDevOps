# Docker Compose - MySQL + PhpMyAdmin

## Objetivo

Gestionar una base de datos MySQL mediante interfaz web PhpMyAdmin.

## Archivo clave

- `docker-compose.yml`

## Comandos

```bash
cd 4-DockerCompose/phpmyadmin
docker compose up -d
```

## Verificacion

- PhpMyAdmin: `http://localhost:8081`
- MySQL: `localhost:6033`

## Credenciales de ejemplo

Revisar y actualizar variables de usuario/password del compose para entorno real.
