# Docker Compose - Configuracion Web

## Objetivo

Mantener archivos de configuracion Nginx y contenido web de ejemplo para integrarlos en un servicio Compose.

## Archivos

- `default.conf`
- `webejemplo.html`

## Uso sugerido

Copiar estos archivos en un ejercicio Compose con servicio Nginx para probar configuraciones de virtual host y archivo index personalizado.
