# Jenkins - Ejercicios

## Archivos

- `hello.Jenkinsfile`: pipeline minimo de demostracion.
- `real.Jenkinsfile`: pipeline multi-stage con post actions.

## Objetivo

Entender sintaxis declarativa de Jenkins y ciclo completo de pipeline.

## Uso recomendado

1. Crear un Pipeline Job en Jenkins.
2. Pegar el contenido del Jenkinsfile elegido.
3. Ejecutar y revisar logs de cada stage.
