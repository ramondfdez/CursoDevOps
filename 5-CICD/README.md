# 5 - CI/CD

## Objetivo

Introducir pipelines de integracion y despliegue continuo con GitLab CI y Jenkins.

## Contenido

- `Gitlab/`: ejemplos de `.gitlab-ci.yml`.
- `Jenkins/`: pipelines declarativos en `Jenkinsfile`.

## Resultado de aprendizaje

- Definir stages y jobs.
- Automatizar build, test, empaquetado y despliegue.
- Entender diferencias entre herramientas CI/CD.
